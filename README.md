# soft-to-rigid

**Shape continuation as an alternative search for packing congruent shapes.**

To pack *n* copies of a shape into the smallest container, most searches move rigid pieces. *Hardening* starts every piece as the disk inscribed in it and deforms it into the target shape while the container is pushed inward. It found a new packing of 12 unit cubes in a cube ([soft-to-rigid-packing](https://github.com/yoheinakajima/soft-to-rigid-packing)). This repository asks whether it is a search worth running alongside existing ones, in a controlled study: five searches, seven families of shapes and containers plus four held out from development, matched budgets and tuning, every experiment planned before it ran, and every run replayable.

- **Site:** <https://yoheinakajima.github.io/soft-to-rigid/> — the answer in four lines, paired replays, every instance and method, the journal of every experiment.
- **Paper:** [paper/main.pdf](paper/main.pdf) ([source](paper/)), also on the [site](https://yoheinakajima.github.io/soft-to-rigid/paper.html).
- **Journal:** [JOURNAL.md](JOURNAL.md) — every experiment in order: question, expectation, rule, findings (corrections included), decision.

## What we found

<!-- headline:start -->
*(generated by `python3 -m packing.project`; do not edit)*

1. **Not a better default.** Tuned with comparable effort, rigid starts reach the lowest container size on 155 of 188 instances, hardening on 142 ([C07](https://yoheinakajima.github.io/soft-to-rigid/journal.html#C07-breadth-best)).
2. **A different search.** On squares in a square hardening is lowest on 27 of 28 instances and the only search that low on 5, including Trump's n = 11 and Wainwright's n = 19; at ten times the budget it alone reaches the best known packing for n = 17 and 26 ([C16](https://yoheinakajima.github.io/soft-to-rigid/journal.html#C16-squares-long)).
3. **Consistent with the gradual rounding, not proven.** Compressing disks then switching to polygons at once ([C11](https://yoheinakajima.github.io/soft-to-rigid/journal.html#C11-snap)), or growing rigid polygons along hardening's area schedule ([C12](https://yoheinakajima.github.io/soft-to-rigid/journal.html#C12-grow-area)), shows no detectable difference from rigid starts (20:20 and 15:14 instances lower); the pre-registered test on squares is inconclusive.
4. **It has a cost.** On four families held out from development, hardening is lower than rigid starts on 3 instances and higher on 17; a short pilot that picks the path per instance does no better than always starting rigid ([C15](https://yoheinakajima.github.io/soft-to-rigid/journal.html#C15-heldout-decision)).
<!-- headline:end -->

The path through shape space is a factor in which packings a search finds, not a better method. Keep hardening beside rigid searches where it reaches different packings; we have not shown that splitting a fixed budget between them pays, and we have no test that predicts in advance where it helps. Details and caveats are in the paper.

## Downstream use

The earlier cube release has been continued and extended by others: [cubes-in-cube-n13](https://github.com/tronford/cubes-in-cube-n13) (the n = 13 search, with re-melt and insertion moves), [platonic-packing](https://github.com/alejandrozu/platonic-packing) (all five Platonic solids, exact checks over Q(√2, √5)), and [tesseract-packing](https://github.com/hockyy/tesseract-packing) (four dimensions). They are not part of the controlled study; the paper's discussion says what each does and does not show.

## Reproduce

```bash
python3 -m pip install activegraph numpy scipy matplotlib
node engine/run.js campaigns/C07-breadth-best/plan.json --worker 0 --of 1   # rerun any campaign (resumable, deterministic per seed)
python3 -m packing.polish C07-breadth-best                                 # tightening of the candidates
python3 -m packing.ledger rebuild                                           # rebuild the research ledger from plans, runs and notes
python3 -m packing.project && python3 -m packing.analyze && python3 -m packing.stats && python3 -m packing.ablations
python3 scripts/figures.py && (cd paper && latexmk -pdf main.tex)
```

Runs are deterministic given the seed: rerunning a campaign reproduces every container size and pose exactly (only timestamps and timings differ).
