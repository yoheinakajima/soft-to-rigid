# soft-to-rigid

**Does the path a piece takes through shape space change which packings a search finds?**

To pack *n* copies of a shape into the smallest container, most searches move rigid pieces. *Hardening* starts every piece as the disk inscribed in it and deforms it into the real shape while the container is pushed inward. That approach found a new packing of 12 unit cubes in a cube ([soft-to-rigid-packing](https://github.com/yoheinakajima/soft-to-rigid-packing)). This repository tests it properly: five paths, seven families of shapes and containers, equal budgets, equal tuning effort, every experiment planned before it ran, and every result replayable.

- **Site:** <https://yoheinakajima.github.io/soft-to-rigid/> — results by family, replays of the best run of every instance and method, the research journal, verifiers.
- **Paper:** `paper/` (built PDF on the site).
- **Journal:** [JOURNAL.md](JOURNAL.md) — every campaign in order: question, expectation, rule, result, decision.

## Find your way around

| If you want to… | Look at |
|---|---|
| see what was found | the site, or [JOURNAL.md](JOURNAL.md) |
| check a number in the paper | `paper/numbers.tex` and `paper/tables/` are generated by `packing/analyze.py` from the ledger |
| see exactly what an experiment was | `campaigns/<C>/plan.json` (committed before its first run) and `REPORT.md` |
| get the raw data | `campaigns/<C>/runs*.jsonl` (one line per run, with final poses) |
| watch a run | `campaigns/<C>/replays/` or the family pages on the site |
| verify a packing | `python3 verify.py <claim.json>` (2D), `python3 verify3.py` (cubes), `python3 -m packing.certify` (exact) |
| understand the design | [ARCHITECTURE.md](ARCHITECTURE.md); for AI agents, [AGENTS.md](AGENTS.md) |

## Reproduce

```bash
npm --version && python3 -m pip install activegraph numpy scipy matplotlib
node engine/run.js campaigns/C07-breadth-best/plan.json --worker 0 --of 1 --limit 20   # rerun any campaign (resumable, deterministic per seed)
python3 -m packing.polish C07-breadth-best        # exact tightening of the candidates
python3 -m packing.ledger rebuild                  # rebuild the research ledger from plans, runs and notes
python3 -m packing.project && python3 -m packing.analyze && python3 scripts/figures.py
```

Runs are deterministic given the seed: rerunning a campaign reproduces every container size and pose exactly (only timestamps and timings differ).
